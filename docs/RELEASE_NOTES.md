# 판저 프론트 Ausf.B PS2 유럽판 한글 패치 v1.0

SLES-52984 유럽 원본용 정식 한글 패치입니다. 첨부 파일은 한글 패치 xdelta와 PCSX2 16:9 와이드 패치 pnach 2종이며, 원본 ISO·게임 파일·폰트는 제공하지 않습니다.

- 무전·이벤트 메시지, 메뉴·옵션·메모리 카드 안내, 전차명 134종, 부대·콜사인명 약 1,200종, 승무원·방향·차종 이름표, 전투 지휘 메뉴 한글화(외부 기계 번역 미사용).
- 메인 메뉴·미션 목록·국가명·타이틀·로딩·제작진 이미지, 브리핑 본문 30쪽·지도 라벨 25장·머리글 지명 한글화.
- 일본판 엔진의 한자 폰트 칸에 한글 509자를 넣어 표시(ELF 코드 무수정). 본문은 원본 영문처럼 굵고 넓은 배민 도현체, 전투 HUD는 갈무리11 Condensed.
- 직접 만든 PCSX2 16:9 와이드 패치 포함(3D 시야 확장, 컬링·하늘 보정, HUD·메뉴 비율 유지).
- PCSX2에서 부팅·메뉴·옵션·전술·미션 목록·브리핑·전투(무전·HUD·지휘 메뉴·분대 편성/지휘)·쌍안경·조준경·와이드 패치 확인, 공개 소스 재빌드 및 xdelta 복원 해시 일치. 전체 미션 플레이, 전투 결과·보급/지원 세부 화면, 저장/불러오기, 실기는 미검증입니다.

## 첨부 파일

- `Panzer_Front_AusfB_KO_v1.0.xdelta`: 한글 패치(유럽 원본 ISO용)
- `SLES-52984_3F014BD7.pnach`: PCSX2 16:9 와이드 패치 — **한글판 ISO용**(게임 CRC 3F014BD7)
- `SLES-52984_F2694B94.pnach`: PCSX2 16:9 와이드 패치 — 원본 유럽판(영문) ISO용(게임 CRC F2694B94)

## 한글 패치 적용

1. xdelta3(또는 xdeltaUI)를 준비합니다.
2. 원본 `Panzer Front Ausf.B (Europe).iso`의 SHA-256이 아래 값과 같은지 확인합니다.
   - PowerShell: `Get-FileHash ".\Panzer Front Ausf.B (Europe).iso"`
3. 명령: `xdelta3 -d -s "Panzer Front Ausf.B (Europe).iso" Panzer_Front_AusfB_KO_v1.0.xdelta "Panzer Front Ausf.B (Korean).iso"`
   - xdeltaUI: Patch에 xdelta, Source File에 원본 ISO, Output File에 만들 ISO 이름을 넣고 Patch를 누릅니다.
4. 만든 ISO의 SHA-256이 아래 완성 ISO 값과 같으면 정상입니다.

## 16:9 와이드 패치 사용법

PCSX2 내장 패치 모음과 웹에 이 게임용 와이드 패치가 없어 직접 만들었습니다. 한글 패치는 실행 파일의 문자열을 바꾸므로 게임 CRC가 원본 F2694B94에서 **3F014BD7**로 바뀝니다. PCSX2는 CRC로 패치 파일을 찾으므로 버전별 파일을 따로 첨부했습니다(내용은 같음).

**무엇이 바뀌나**
- 3D 화면: 시야를 좌우로 넓혀 16:9로 보여 줍니다(4:3 화면을 늘리는 방식이 아님). 일반 시점·쌍안경(L3)·조준경(○) 모두 적용.
- 컬링·하늘: 화면 가장자리의 물체와 하늘이 끝까지 그려지도록 보정.
- HUD·메뉴: 늘어나지 않고 원래 비율로 화면 중앙에 그려집니다(좌우 여백).
- 패치 안에 `gsaspectratio=16:9`가 들어 있어 화면 비율도 자동으로 16:9가 됩니다.

**PCSX2 2.x(권장)**
1. 사용하는 ISO에 맞는 pnach를 `문서\PCSX2\patches\`(포터블은 `PCSX2 폴더\patches\`)에 넣습니다.
   - 한글판: `SLES-52984_3F014BD7.pnach` / 원본 영문판: `SLES-52984_F2694B94.pnach` (둘 다 넣어도 됩니다)
2. 게임을 시작하면 자동으로 적용됩니다(패치 묶음 이름이 없어 패치 탭에서 따로 체크할 필요 없음). 화면 왼쪽 위에 패치 활성화 알림이 뜹니다.
3. 화면이 16:9로 바뀌지 않으면 게임 목록에서 오른쪽 클릭 → 속성 → 그래픽 → 디스플레이 → 화면 비율 **16:9**.
4. 끄려면 `patches` 폴더에서 pnach를 빼거나 이름을 바꿉니다.

설정 파일로 화면 비율을 고정하려면 `문서\PCSX2\gamesettings\SLES-52984_3F014BD7.ini`에 다음을 저장합니다.

```ini
[EmuCore/GS]
AspectRatio = 16:9
```

**PCSX2 1.6** — 파일 이름을 `3F014BD7.pnach`(원본은 `F2694B94.pnach`)로 바꿔 `cheats_ws` 폴더에 넣고, 시스템 → 와이드스크린 패치 사용을 켠 뒤 비디오 → 창 설정에서 16:9를 고릅니다(1.6은 미검증).

**알려진 한계**: 먼 지평선 좌우 끝의 지형이 약간 잘릴 수 있고, 메뉴·브리핑 화면은 좌우가 비며, 쌍안경 테두리·조준경 눈금은 가로로 늘어나 보일 수 있습니다. 실기에서는 쓸 수 없습니다. 자세한 내용은 저장소의 docs/WIDESCREEN.md를 보세요.
