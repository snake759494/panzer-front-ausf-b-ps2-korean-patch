# PCSX2 16:9 와이드 패치 사용법

PCSX2에 내장된 커뮤니티 패치 모음과 웹 어디에도 이 게임(SLES-52984)용 와이드 패치가 없어 직접 만들었습니다.

| 파일 | 대상 | 게임 CRC |
|---|---|---|
| `SLES-52984_3F014BD7.pnach` | 한글 패치를 적용한 ISO | 3F014BD7 |
| `SLES-52984_F2694B94.pnach` | 원본 유럽판(영문) ISO | F2694B94 |

한글 패치는 실행 파일(SLES_529.84)의 문자열을 바꾸므로 PCSX2가 계산하는 게임 CRC가 원본 **F2694B94**에서 **3F014BD7**로 바뀝니다.
PCSX2는 CRC로 패치 파일을 찾기 때문에 CRC별 파일을 따로 둡니다. 와이드 패치가 고치는 코드는 두 버전이 같아 내용은 동일합니다.

## 무엇을 고치나

1. **3D 화면**: 투영 행렬(sceVu0ViewScreenMatrix, 0x1106A0)의 가로 배율에 0.75를 곱해 시야를 좌우로 넓힙니다(화면을 늘리는 방식이 아님).
2. **컬링**: 클립 행렬의 가로 범위를 4/3배로 넓혀 화면 가장자리의 물체도 그립니다.
3. **하늘·원경**: 하늘 메시 폭을 정하는 시야각 계산의 화면 반폭 256을 340으로 바꿔 하늘이 화면 끝까지 채워집니다.
4. **HUD·메뉴(2D)**: 2D 그리기 함수 7개의 가로 배율·오프셋을 바꿔 화면 중앙의 4:3 영역에 원래 비율로 그립니다(좌우 여백).
5. 패치 안에 `gsaspectratio=16:9`가 있어 화면 비율도 자동으로 16:9가 됩니다.

일반 시점, 쌍안경(L3), 조준경(○) 모두 같은 투영 함수를 쓰므로 함께 넓어집니다.

## PCSX2 2.x (Qt) — 권장

1. 사용하는 ISO에 맞는 pnach 파일을 PCSX2 사용자 폴더의 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches\`
   - 포터블판: `PCSX2 폴더\patches\`
   - 한글판과 원본을 모두 쓴다면 두 파일을 함께 넣어도 됩니다(CRC가 달라 섞이지 않음).
2. 게임을 시작하면 자동으로 적용됩니다. 패치 묶음 이름이 없는 패치라 따로 체크할 필요가 없습니다.
   화면 왼쪽 위에 패치가 활성화되었다는 알림이 뜹니다.
3. 화면이 16:9로 바뀌지 않으면 게임 목록에서 게임을 오른쪽 클릭 → **속성(Properties)** → **그래픽(Graphics) → 디스플레이(Display)**에서
   **화면 비율(Aspect Ratio)**을 **16:9**로 바꿉니다.
4. 끄려면 `patches` 폴더에서 pnach 파일을 빼거나 이름을 바꿉니다.

설정 파일로 화면 비율을 고정하려면 `문서\PCSX2\gamesettings\SLES-52984_3F014BD7.ini`(원본은 `_F2694B94.ini`)에 다음을 저장합니다.

```ini
[EmuCore/GS]
AspectRatio = 16:9
```

## PCSX2 1.6 (wxWidgets)

1. 파일 이름을 CRC만 남겨 `3F014BD7.pnach`(원본은 `F2694B94.pnach`)로 바꿔 `cheats_ws` 폴더에 넣습니다.
2. **시스템(System) → 와이드스크린 패치 사용(Enable Widescreen Patches)**을 켭니다.
3. **설정(Config) → 비디오(Video) → 창 설정(Window Settings)**에서 화면 비율을 16:9로 바꿉니다.
   (1.6에서는 미검증입니다.)

## 알려진 한계

- 먼 지평선 좌우 끝의 지형이 약간 들쭉날쭉하게 잘릴 수 있습니다.
- 메뉴·브리핑 화면은 4:3 영역만 그려지고 좌우가 빕니다.
- 쌍안경 테두리·조준경 눈금은 다른 2D 경로로 그려질 수 있어 가로로 늘어나 보일 수 있습니다.
- PCSX2 2.2(Vulkan)에서 훈련·메르도르프 전투, 쌍안경·조준경, 메뉴·브리핑 화면을 확인했습니다. 실기(PS2)에서는 쓸 수 없습니다(에뮬레이터 전용).
