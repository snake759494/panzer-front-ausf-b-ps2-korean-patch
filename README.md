# 판저 프론트 Ausf.B · PS2 유럽판 한글 패치 v1.0

대상: **Panzer Front Ausf.B (Europe), SLES-52984**

비공식 팬 한글 패치입니다. 적법하게 보유한 유럽판 원본 ISO에 xdelta 패치를 적용해 사용합니다.
릴리즈 첨부 파일은 xdelta와 PCSX2용 16:9 와이드 패치(pnach)이며 원본·완성 ISO, 게임 파일, 폰트는 배포하지 않습니다.

## 패치 적용

| 파일 | SHA-256 |
|---|---|
| 원본 `Panzer Front Ausf.B (Europe).iso` (1,308,360,704바이트) | `f37f08210c361975432bb47d8f0601c897c4e9c6994e55cbf89767f2c7b37f55` |
| 완성 `Panzer Front Ausf.B (Korean).iso` (1,308,360,704바이트) | `4bc20ac6882c9865d5aa634ad9a02e92b06ee54c67e17e8b5eb80b7ec90ef1cf` |
| `Panzer_Front_AusfB_KO_v1.0.xdelta` | `a89e6b07ef62e3913cdc31d685a2129cd875ca5bfc18be0362ae3a59d4730578` |

```powershell
xdelta3 -d -s ".\Panzer Front Ausf.B (Europe).iso" .\Panzer_Front_AusfB_KO_v1.0.xdelta ".\Panzer Front Ausf.B (Korean).iso"
```

## 16:9 와이드 패치

PCSX2 내장 패치 모음과 웹에 이 게임용 와이드 패치가 없어 직접 만들었습니다. 3D 시야를 넓히고(화면 늘리기 아님)
컬링·하늘 폭을 보정하며, HUD·메뉴는 원래 비율로 화면 중앙에 그립니다. 한글판 CRC(**3F014BD7**)용과
원본 CRC(**F2694B94**)용 pnach를 함께 첨부합니다. 사용법은 [docs/WIDESCREEN.md](docs/WIDESCREEN.md)를 보세요.

## 한글 표시 방식

1. **본문 폰트**: 영어판이지만 일본판 엔진을 그대로 써서 Shift-JIS 텍스트와 `\D\FO\FONT.DAT`(코드표)·`FONT.PZA`
   (8플레인 1bpp 16×16) 폰트를 쓴다. 한자 칸 1,348개 중 509칸에 한글을 그려 넣고 그 SJIS 코드로 텍스트를 기록했다
   (ELF 코드 무수정). 원본 영문이 굵고 가로로 넓은 글꼴이라 **배민 도현체**를 칸에 꽉 채워 그렸다.
2. **제목 글자**(`PFFONT.PZA`): 큰·중간 글자는 영문 칸에, 작은 글자는 0xA1~0xBF 칸에 한글 음절을 그려 해당 코드로 기록.
   작은 글자 렌더러는 0xC0 이상을 그리지 않고 칸마다 원래 글자 폭만큼만 잘라 그려서 그 폭 안에 그린다.
3. **전투 HUD**(`OT\TH\SCR.PZA`): 9px 간격 글꼴(글자 번호 = 코드-0x44)의 0xA2~0xDF(62자)에 **갈무리11 Condensed**를
   원래 크기로 그리고 원본처럼 가로 1px 굵게 했다. 원본과 같은 색(13번)으로 칠해 비선택 항목도 잘 보인다.
   62자 제한 때문에 탄종·전투 메뉴는 간결하게 옮겼다(예: 피모철갑고폭탄 → 철갑고폭).
4. **이미지**: 나눔스퀘어 네오로 다시 그리고 원본 팔레트로 양자화. 브리핑 지도 라벨은 원래 글자를 지우고 주변을 복원한 뒤 그렸다.
5. **D.PAK**: 바뀐 항목을 끝에 붙이고 목차만 수정.

## 검증

- PCSX2 2.2: 부팅·메모리 카드 안내, 타이틀, 메인 메뉴, 옵션, 전술(국가·부대명), 미션 목록, 작전 브리핑(본문·지도·머리글),
  훈련·메르도르프 전투(무전 메시지, HUD 탄종, 지휘 메뉴·분대 편성·분대 지휘), 쌍안경·조준경 시점, 16:9 와이드 패치.
- 공개 소스 재빌드 결과와 xdelta 복원 ISO SHA-256 일치.
- **미검증**: 전체 미션 플레이, 전투 결과 화면, 보급·지원 요청 세부 화면, 저장/불러오기, 실기.
